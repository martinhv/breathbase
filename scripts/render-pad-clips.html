Pad clip render

Bakes the 8 chord pad clips (cello + pad + strings + air noise) into pad-chord-0.wav through pad-chord-7.wav.

Open this file in a desktop browser (Chrome/Firefox) and click the button. The browser will trigger 8 file downloads. Then run scripts/encode-pad-clips.sh ~/Downloads to convert to MP3 and place the files in public/sounds/.

Each clip is 24 s long: ~3 s attack swell, ~18 s sustained body, ~3 s release tail. The runtime engine crossfades between clips when the chord progression advances.
